# Darkroom

A simple, sleek, native macOS RAW photo editor. Point it at a folder of RAW files,
pick a photo, and edit — non-destructively, at full quality, with no subscription.

- Native Swift/SwiftUI, Apple's RAW engine, Metal-backed live preview
- Non-destructive: edits live in sidecar files, originals untouched
- Built around a Sony RX100 IV workflow; supports any camera on Apple's RAW list

Status: pre-build. See `docs/ROADMAP.md` and `docs/adr/` for direction and decisions.
